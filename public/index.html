LearnHub

A full-stack learning management system: Node.js/Express API, MongoDB, JWT sessions, and server-side exam grading.

This Express application is designed to run as a long-running server (e.g. on Render or Railway). This static page is deployed by Netlify while the full app runs elsewhere.

  • Start the API locally with npm start
  • Configure the environment with .env.example as a template
  • API health check available at /api/health
